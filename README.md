# Contoso Field Service — Dispatcher Console (public demo)

Static, demo-data build of the Dispatcher Console, a Power Apps code app built for the Builder's Journey
(Zero To Hero Academy). No sign-in; the data is a seeded scenario for the Microsoft Ignite 2026 venue
build-out at Moscone Center, San Francisco. Contoso Field Services is a fictional organisation; built with
Microsoft tooling, not by Microsoft.

- Live demo: https://danielminton.github.io/fieldservice-dispatcher-demo/
- `data/workorders.json`: read-only snapshot of the Dataverse work orders, used by the public
  Copilot Studio agent "Field Service Assistant".

Source, Dataverse model, flow, agent and tests live in the main repository.
